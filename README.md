# 海景别墅 · 3D 装修方案

纯前端三维展示：Three.js（本地化，无需 CDN），单文件场景，无外部模型/贴图依赖。

## 页面

| 文件 | 内容 |
|---|---|
| `villa-L.html` | **推荐** · 双层布局：底层客厅/卫浴正对海，二层 6 间套房 + 主卧，西翼构成 L 形平面 |
| `index.html` | 单层版本：6 间卧室一字排开，可直接俯视内饰 |
| `gallery.html` | 全景图画廊（左侧导航 + 淡入淡出），把效果图放进 `images/` 即生效 |

## 操作

- 左键拖拽旋转 · 滚轮缩放 · 右键平移
- 数字键 `1`–`9` 切换视角（`villa-L.html`），`R` 切换屋顶
- 地址栏 hash 直达：`#living` `#bath` `#bed1` `#night`，性能模式加 `?lite=1`

## 本地运行

双击 `start.cmd`（起本地服务并打开浏览器），或：

```bash
python -m http.server 8899
```

## 说明

- 三维为**方案示意**：几何体按米制建模，面积标注为设计任务书数值，非精确测绘。
- 家具为程序化几何组合，材质由 Canvas 生成（木纹/大理石/织纹），追求"结构清楚 + 交互流畅"，非照片级渲染。
- 效果图级呈现请看 `生图提示词.md`：按里面的配方生成 6 张图放进 `images/`，`gallery.html` 会直接使用。
